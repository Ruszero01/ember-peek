# PSD / PSB 合成预览

官方 `ember.psd` 插件只查看文件保存的最终合成图像，不解析、重合成或编辑图层，也不修改原文件。支持 PSD v1 和 PSB v2 的 8 位 RGB、灰度合成图，以及 raw / PackBits RLE 压缩；其他位深、颜色模式、ZIP 压缩或缺失合成图明确报错，不用低清缩略图冒充最终图像。保存时需启用 Photoshop 的兼容性合成图。

## 性能与显示契约

- `open` 只读取 26 字节头部，返回原始尺寸、预览尺寸与传输大小，让网页先完成窗口准备。
- `render` 通过长度字段和 64 位定位跳过颜色数据、资源与图层区，直接读取合成图；不将整个文件装进内存，文件大小不受网页 `fileUrl()` 的 128 MiB 上限限制。
- 预览最长边为 2560 像素，保持比例、不放大小图。raw/RLE 仅读取输出需要的行，行内按位置采样；这是速度优先的只读预览，细线在缩小后可能丢失，不用于逐像素校对。
- 显示保存的 RGB 值或灰度值，按不透明合成图处理；附加 alpha/专色通道不解释，ICC 色彩管理不在本版范围内。
- 原生缓存在会话内保存 RGBA 字节，`pixels` 每次最多传输 512 KiB（base64）。`open` 和 `render` 的响应只含小型元数据；切换视口复用当前会话，`release` 清理缓存。解码串行化，缓存总量限制为 128 MiB。
- 网页用 canvas 渲染图像，默认适应窗口；支持滚轮缩放、左键拖动平移，宿主工具栏提供百分比缩放（scrub）、适应窗口和原始尺寸按钮。缩放按原始文档尺寸计算，100% 表示文档像素对应 CSS 像素；始终复用最长边 2560 像素的预览，不重读、不重新解码，放大不增加细节。`status()` 显示原始尺寸、缩放比例、预览尺寸和错误。无图层、编辑或导出功能。
- 适应模式在窗口尺寸和主题／视口模式变化时重新适配；手动缩放或拖动退出适应模式，点击适应窗口重新进入并居中。普通视口保留两条栏的安全区域，沉浸视口使用完整窗口。背景使用与图片预览相同的 16px 点纹与主题边框色。拖动越界使用 22% 阻尼，最多额外移动 32 CSS 像素；松手、指针取消或丢失捕获后，在 280ms 内平滑回到可达边界。系统开启减少动态效果时直接回到边界。新拖动、缩放、适应、尺寸或主题变化中断回弹，避免动画覆盖用户操作。拖动和缩小后至少保留一条可见边缘，画面不会完全移出视口。画布大小仅随视口和设备像素比变化，缩放不会分配原始图像尺寸的画布。

## 验证

原生测试覆盖 PSD/PSB 的 raw/RLE 像素一致性、PackBits 的字面量/重复/空操作、截断与越界拒绝、超过 4 GiB 的图层区跳过、输出预算、分块 RPC 和释放。真实样例只在本机验证，不提交项目资产。
