# 办公预览插件

第一版提供三个独立的只读插件：Word（DOCX）、PPT（PPTX）、Excel（XLSX）。无需安装 Microsoft Office，不支持旧二进制 DOC/PPT/XLS、加密文件或宏文件；不提供编辑、保存、转换或公式计算。

## 分层与共享代码

宿主继续只提供 api:1 的文件读取、原生命令、控件、状态与生命周期，不识别办公格式。三个原生进程分别链接 crates/office-document 的 OOXML 校验库；库编译进插件可执行文件，更新它只需重建并发布受影响插件。插件网页按需复制 SDK document.js/document.css，构建标识覆盖共享代码；无需为本次功能升级宿主或协议。

每种格式的渲染依赖和业务留在对应插件。依赖固定版本、本地随包分发，来源、许可证和摘要记录在各插件 ui/dependencies.json；运行时不依赖 CDN。

Word 与 PPT 另通过支持 `sidebar()` 的宿主提供页面缩略图侧栏，默认显示（可在设置中关闭），可拖动调宽并记住宽度；正文视口随之切分，点击缩略图跳页，当前页随正文同步。侧栏复用同一插件入口的 sidebar 角色和已解析内容，通过 peer 传递导航状态，宿主不解释页码。缩略图列表只挂载可见及邻近行，最多保留 32 张图；单张快照最多 1 MiB，超出预算或渲染失败仍保留可点击页码。Word 使用实际分页排版的静态快照；PPT 使用独立的小型渲染容器，复用已解析模型，不再读取整份文件。

## 读取与安全预算

压缩文件上限 64 MiB，最多 4000 个 ZIP 条目，单条解压上限 32 MiB，总解压上限 256 MiB。原生端流式检查实际解压长度、CRC、所需主 XML；拒绝加密、危险路径、重复条目、符号链接、宏以及 XML DTD/实体声明，不解压到磁盘。网页使用现有 read 通道每次读取 1 MiB，并检查完整长度。预算针对快速预览，超过预算给出错误，不无限扩大内存。

预览不执行宏、嵌入脚本或 OLE 对象，不允许文档链接导航；外部资源受现有插件 CSP 约束。所有表格文本使用 textContent。

## 各插件行为

- Word：docx-preview 0.4.1；查看段落、表格、内嵌图片及页眉页脚，按文档显式分页展示（忽略可能重复的已保存分页标记）；保留文档文字颜色并补齐未显式指定样式的默认段落样式，支持具有 VML 回退的页面大小底层组合背景（纯色与内嵌位图）；单页／连续阅读、翻页、页码、1%–800% 缩放、铺满／整页适配与旋转。浏览器排版不保证与 Word 完全相同，不重新计算 Word 的自动分页；禁用 altChunk、修订和评论渲染。
- PPT：@aiden0z/pptx-renderer 1.3.0；单页只渲染当前幻灯片，连续模式保留可见与相邻幻灯片（最多 32 张），延迟加载媒体和幻灯片；翻页、页码、1%–800% 缩放、铺满／整页适配与旋转。展示文字、形状、表格、内嵌图片等静态内容，不播放动画/切换，不保证所有图表、字体和 EMF/WMF 效果；不启用 PDF 嵌入回退。
- Excel：SheetJS CE 0.20.3 在 Worker 内解析，主线程只获取当前可见行；每次最多 200 行、最多 256 个工作表，读取前 100000 行，每个使用区域最多 256 列，截断时状态栏提示。支持工作表切换、行列标号、缩放、数值格式及公式缓存结果；没有缓存的公式展示公式文字。不重算公式，不还原图表、图片、合并单元格和完整单元格样式。

视口仅放文档内容；翻页、工作表切换和缩放走宿主 controls，页数/表名/限制走 status，错误通过 presented 返回。所有插件保持独立安装和版本发布。

PDF、PPT、Word 的插件设置统一为阅读模式（默认单页）、默认适配窗口（默认铺满）与默认显示缩略图（默认开启）。设置修改立即生效；工具栏适配切换只影响当前文档。整页适配的单页在安全视口内居中，连续模式保持顶部阅读顺序；手动缩放保留当前页顶部阅读位置，不进行中心补偿。旋转仅改变预览，不修改源文件。

PPT 渲染器只接收内部容器，不可接管分页表面或离屏容器的定位。离屏源／缩略图容器固定定位并约束尺寸；分页边界裁去变换前的几何溢出，正文滚动仅由视口承担。尺寸通知按帧合并，实际可用宽高不变时不重复布局。

铺满模式基于视口边框盒扣除边框与安全留白后的稳定高度计算，横向滚动条显隐不改变铺满比例；整页适配使用实际可用高度。
