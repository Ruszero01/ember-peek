# 音频预览初版

`ember.audio` 是独立只读插件，版本 `0.1.0`；宿主只提供现有媒体范围读取、通用控件和消息通道，不解析音频。界面归属遵循[插件能力协议](plugin-capabilities.md)。

## 格式与路径

清单匹配 MP1/MP2/MP3/MPA、WAV/WAVE、FLAC、OGG/OGA/OPUS、AAC/ADTS、M4A/M4B/M4R、AIF/AIFF/AIFC、CAF、MKA、WEBA。扩展名是容器入口，不代表任意内部编码都能解码。

- 优先把 `streamUrl()` 交给 `<audio>`，使用系统媒体引擎按 Range 读取。MP3、FLAC、PCM WAV、AAC/MP4、Ogg Vorbis/Opus 等常见编码可以直接播放；实际支持取决于 WebView2 与系统编解码器。
- 系统解码失败或 12 秒内不能准备播放时，使用随插件打包的 Symphonia 0.5.5 解码器，不要求安装 FFmpeg。内置支持 PCM、ADPCM、FLAC、MPEG Layer I/II/III、Vorbis、AAC-LC 和 M4A 中的 ALAC；CAF 已验证 PCM。不是所有 CAF/AIFF/MKA 编码组合都支持。
- Opus 由系统媒体引擎播放；内置兼容解码器不支持 Opus、HE-AAC、WMA、APE、WavPack、DSD 或 MIDI。损坏、加密或超出限制的文件明确报错，不伪装为成功。
- `ogg` 可同时匹配视频插件；音频默认优先级 110，用户仍可切换到视频视口。没有独占扩展名或插件 ID 特判。

## 交互与生命周期

音频采用专用视口布局：文件名、格式、整段音频的真实波形、播放／暂停、当前时间与总时长集中放在视口内部，不声明独立浮层。音频没有需要让出空间的文档或视频画面，因此视口允许这些播放器操作；此例外不改变宿主与插件的业务边界。右下角工具栏提供静音、音量、循环和 0.25–4× 倍速；宿主信息栏继续显示播放状态，波形轨道本身兼任进度区，点选／拖动定位，已播放部分着色；下方提供前后 5 秒与紧凑的播放按钮组。不解码封面。

K 切换播放，左右箭头前后跳 5 秒，Home 回到开头；无修饰空格沿用宿主隐藏预览。未知时长时显示未知且禁用绝对进度跳转，仍可播放。默认自动播放、音量 80%、不循环；音量与循环持久化，倍速仅影响当前视图。系统播放路径保留媒体引擎的音调处理，兼容路径通过 Web Audio 播放速率实现倍速，音调随速率变化。

隐藏或切换视口暂停；仍保留的网页返回后不自行恢复播放，重新打开或重建网页按自动播放设置初始化。初始化在后台可继续完成，但只在可见且开启自动播放时开始播放。初始视图真正可播放后才 `presented()`，失败汇报错误；兼容路径先完成第一块解码，再汇报可用。卸载网页停止播放并关闭 AudioContext，会话 `release` 释放原生解码器与文件句柄。不写原始文件或输出转码文件。

## 性能与配额

音量调节保持插件本地待保存草稿，迟到的旧保存快照不能覆盖新的调节值；收到最新值的确认后才恢复外部设置同步。设置写入失败时回到当前配置，卸载取消待保存定时器。

原生 `open` 只返回格式标签，不读取文件，不启动外部工具。兼容路径通过 `audio-read` 延迟打开解码器，后续顺序读取保持同一解码器与文件句柄；显式 seek 使用准确定位、reset 和目标采样点前的丢弃。

每次最多输出约 2 秒且不超过 2 MiB 的交错 float32 PCM；base64 位于单条 8 MiB 协议消息预算内。网页将 PCM 转为 AudioBuffer，按 AudioContext 时间连续调度，不靠反复替换 WAV/Blob 拼接。预缓冲保留约 4 秒源音频，最多多一块；倍速不会扩大为整曲缓存。请求串行，跳转使用代次抛弃过期回复。

波形通过独立的 `waveform-read` 解码游标在后台分批生成，不阻塞 `presented()` 或首播、不改变播放解码器的位置。每次以约 16 ms 工作预算／最多 128 包推进（单包不可抢占），网页间隔 16 ms 发起下一次请求；隐藏后停止请求，会话释放清除分析游标。可见且暂停时仍可完成波形分析。分析直接聚合解码后的采样，不经过播放 PCM 队列。

各声道采样的真实最小／最大值合并为时间峰值，最多保留 2048 组；未知长度或估计偏差通过两两合并、自适应扩大时间桶保持有界，并保留瞬态极值。只传输峰值，不把整曲 PCM 交给网页。生成期间保留时间与可操作进度输入；超过 400 ms 才显示生成进度，完成后整段波形以 160 ms 淡入，减少反复伸长、改动归一化与重画时间刻度的跳动，不伪造占位波形。减少动态效果时直接显示。内置解码器不支持的编码（例如 Opus）仍可系统播放，但显示波形暂不可用。

轨道使用随插件打包的 WaveSurfer.js 7.12.12 与 Timeline 插件，负责按设备像素比绘制 Canvas 波形、已播放区域、播放头与时间刻度。原生峰值映射为最多 4096 个有符号浮点样本，未分析区补零；通过空 URL、峰值与时长加载，不触发 WaveSurfer 的整文件下载或浏览器解码。库绑定单独的无音源媒体元素，显示进度不会跳转或中断真实播放器。窗口尺寸变化由库重新布局；播放时只更新进度，暂停或隐藏取消动画帧，点选、拖动和键盘操作沿用可访问进度输入并交给现有播放后端。

兼容路径限 1–8 声道、8–192 kHz；单包最多 1,048,576 个采样值，单次最多遍历 8,192 包。元数据预算 256 KiB，不读取内嵌封面。未知或损坏数据不能无限增长 PCM、队列或解析循环。

## 验证

Rust 使用提交的自生成短音频样本覆盖 PCM WAV、PCM AIFF、FLAC、MP3、MP2、Vorbis、AAC-LC、ALAC/M4A、PCM CAF 和 IMA ADPCM WAV，无需测试机安装 FFmpeg；另测长音频分块、准确跳转、无效参数、波形缓存压缩保留极值以及分析不改变播放位置。Node 测试验证声道拆分、连续调度、缓存边界、暂停、倍速、迟到跳转回复、峰值映射、进度边界、时间刻度及播放头生命周期。

真实 Windows 验收使用用户运行的共享应用：试听常见系统播放格式与 AIFF/ALAC 兼容路径，拖动跳转、调节音量／倍速、循环、切换视口及隐藏后静音，测试长录音、损坏文件、未知时长和不支持的编码。自动测试不能替代声卡输出与实际听感检查。

顶部只显示文件名与格式，不重复显示宿主工具栏已有的插件名称。

音频界面采用工作台式布局：文件名与格式保持克制，整宽波形以细密采样条呈现，不添加轨道标题或卡片边框；时间与播放按钮紧邻轨道，前后跳转按钮标明 5 秒。悬停轨道显示目标时间，点选与拖动仍使用原进度输入；键盘焦点可见，小窗口压缩留白与按钮尺寸，减弱动态效果设置下不缩放按下的播放按钮。配色与字体继承宿主主题。
