# 模型快速预览

官方 `ember.model` 为独立的 `api:1` 只读插件，版本保持 `0.1.0`。目标是辨认资产的形状与基础颜色；不提供编辑、离线渲染或工程执行。宿主不识别模型格式，读取、解析和操作均属于插件。

## 格式与统一视图

| 格式 | 读取方式 | 基础显示范围 |
| --- | --- | --- |
| GLB / glTF 2.0 | 随包 Three.js GLTFLoader | 网格、对象变换、基础颜色与普通贴图；不播放动画 |
| OBJ | OBJLoader + 最多 8 个关联 MTL | 网格、基础颜色、漫反射贴图 |
| FBX | FBXLoader | 解析器支持的网格与基础材质，静态场景 |
| STL | STLLoader | 二进制／文本网格及格式中的基础颜色 |
| PLY | PLYLoader | 网格或点云，顶点颜色 |
| DAE / 3DS / 3MF | 相应 Three.js 解析器 | 网格、对象变换、基础材质；3MF 解压预算另校验 |
| C4D | Cineware S22.008 原生桥 | 已保存的多边形、样条线与可用缓存、对象变换、首个普通材质颜色或对象颜色 |
| Blender `.blend` | MIT `blend` DNA 读取库 | 已保存的基础网格、对象变换、首个材质的 Principled Base Color 或漫反射色 |

所有读取结果进入同一个 Three.js 场景，共用左键旋转、滚轮缩放、右键平移，以及宿主功能栏的缩放、适应窗口、复位视角与线框开关。视口仅放模型内容；状态与控件使用 SDK。模型归一化后显示，单位不会改变交互灵敏度。

功能栏另提供独立的地面网格与 RGB 坐标轴显隐，默认关闭；辅助对象不参与模型统计、边界或适应窗口计算。地面位于归一化模型的下边界，不产生阴影。WebGL 开启 alpha、清屏 alpha 为 0，场景背景为 null，网页空白透明，由宿主通用设置提供点纹／纯色背景。

模型插件设置提供地面、坐标轴、线框三个默认显隐开关，基线均为关闭。新视图读取已保存设置；设置变化更新当前视图中尚未手动切换的项，工具栏的临时选择仅作用于当前视图，不写回默认设置，也不改变相机位置。

GLB 是以后外部转换器可采用的中间格式。已经有网页读取器的格式直接进入统一场景，避免额外转码。当前 `.blend` 不启动 Blender、不调用 Python、不执行工程脚本，也不要求用户安装 Blender；不产生转换文件。

C4D 布尔对象优先显示保存的结果缓存。缺少缓存时，最多 4 个简单差集可以在首帧呈现后，由独立 Worker 临时补算：只接受启用的布尔对象、恰好两个直接多边形操作数、无子层级／操作数缓存，合计最多 3000 个多边形／6000 个三角形。切割体必须通过闭合检查；主体闭合时做实体差集，开放主体只裁掉切割体内的表面，不补封口。单次结果最多 2 万三角形。Worker 从创建起共享 250 毫秒预算（包含启动），到期直接终止；失败、超时、不支持的布局均保留首帧基础网格，不使预览报错。切割体只传作隐藏操作数，不参与初始视口、统计或交互；成功后替换主体几何、更新统计，不移动相机。卸载立即终止 Worker，结果仅留在视图内，不修改源文件、不写持久转换文件。差集／交集未补算时只显示第一个基础操作数，并计入未计算提示。

除上述 C4D 有界差集补算外，C4D / Blender 不计算生成器、修改器、几何节点、约束、绑定姿态或复杂着色器，不保证与原软件最终效果一致。缺少的 C4D 缓存和未计算的 Blender 修改器在状态中提示。C4D 没有可用网格或线条时可显示内嵌 JPEG，但必须标明是静态预览图，并隐藏三维操作。新版 C4D 超出 S22 读取能力可能只能显示缩略图或报错。Blender 支持旧／新块头及 gzip、zstd 压缩；网格兼容性通过 Blender 2.80、2.90、3.0、3.5、4.2、5.2 样例验证，不能据此承诺所有版本和工程布局。新属性存储中的单值属性等未实现布局明确拒绝。

## 性能与资源边界

- 文件上限 1024 MiB，Blender 解压后的文件同样最多 1024 MiB；3MF 中央目录的声明展开总量最多 1024 MiB、4096 项。
- C4D 优先保留原始网格；只有估算超过 400 万三角形的密集场景才按对象分配面数预算并合并相邻网格顶点，尽量保留相邻表面和整个场景的基础轮廓，细小部件可能合并或省略，将输出控制在 400 万三角形内并提示简化，简化场景不补算布尔。不会因三角形超限把整个模型退回静态图。
- C4D 由 SDK 直接读取路径，不提前复制整份文件；仅无可用网格时读取前 4 MiB 查找缩略图。未压缩 Blender 借用读取缓冲，避免再次复制整份文件。网页源文件按 1 MiB 分块传输后解析，当前不承诺流式解析。
- 原生工程预览最多 400 万个三角形、1 万个 Blender 网格对象；网页预览最多 400 万个三角形、1200 万个顶点、1 万个几何对象。
- C4D 层级最多 128 层、10 万个节点；Blender 父层级最多 64 层，块表最多 10 万项，DNA 块最多 8 MiB。拒绝非法索引、非有限坐标、超限几何和截断传输。
- 原生 `open` 只返回大小和格式；`render` 按会话解析一次并缓存无损压缩后的有界几何，`bytes` 每次最多传 2 MiB base64，网页最多 4 个并行请求，按偏移复原并校验每块长度，`release` 清除会话。最多同时保留 4 个原生会话；释放后的解析结果不会重新插入会话表。
- 原生网格采用 gzip 无损压缩后分块传输；`render` 声明 `encoding: gzip` 与 `decodedSize`，网页流式解压到声明大小的单个缓冲，超过声明长度／截断／超过网格与线段的合计字节预算均拒绝。压缩只减少传输，不删减网格。小图保持 raw。
- 原生三角形载荷每顶点 9 个 little-endian float32：位置、平面法线、颜色；原生坐标归一化，网页校验后统一显示。
- 无持续动画循环、无阴影、无阻尼动画。只在交互、窗口／主题变化或贴图完成时通过一帧合并重绘。像素比上限 1.5，卸载时释放 GPU 几何、材质、纹理与图形上下文。
- 基础材质使用 Lambert 光照，保留基础颜色、顶点色、普通颜色贴图、透明度；忽略复杂物理材质和额外着色器。
- 关联资源只允许本地路径、`file:` 与内嵌 data/blob；通过 `resourceUrl` / `resourceBlob` 走现有 `readResources` 权限。模型插件不加载远程或 UNC 资源。单项资源另受宿主 64 MiB 上限保护。缺失 MTL／贴图提示后继续基础几何预览；缺失 glTF 几何缓冲则报错。
- Draco、Meshopt 压缩网格及 KTX2 等需额外解码器的资源暂不支持，不下载解码器，解析器应明确报错。

以上限额用于控制快速预览的工作量，不保证每个文件的加载时间或解析器处理恶意文件时的硬实时／总内存上限。第三方解析器仍处于独立插件进程或隔离网页内，不执行工程脚本。

## SDK 获取与许可

我们自己的模型插件代码、网格桥与读取逻辑遵循仓库 Apache-2.0。Three.js 和 Rust `blend` 分别保留 MIT 许可。Cineware 是专有 SDK，不属于项目的 Apache 授权范围。

Windows 构建先执行 `npm run model:sdk`；插件打包与 npm 的 Rust 门禁会自动执行准备。准备脚本从 [Maxon 官方下载页](https://developers.maxon.net/downloads/) 下载 S22.008，校验固定 SHA-256，只将头文件和两份 release 静态库解到忽略的 `target/cineware-sdk/`。也可设置 `EMBER_CINEWARE_SDK` 使用开发者自己取得的对应 SDK。直接运行 Cargo 前需要准备该依赖。

SDK 随附许可第 2.2 条允许头文件和静态库作为产品的集成部分分发，第 2.3 条禁止修改或分发 SDK 示例与文档。仓库只包含自己编写的适配代码，不提交 SDK 头文件、库、示例或文档；成品包含静态链接的运行代码并保留专有依赖声明。获取／使用 SDK 受其许可约束。构建时的下载不会把用户模型上传给 Maxon。

## 验证

自动化覆盖实际基础网格读取、压缩文件、非法块表、索引／坐标、传输上限、会话释放，以及网页加载器的 OBJ、STL、PLY、GLB/glTF 基础几何和资源规则。Windows 手动验收另确认 C4D 模型形状、旋转、缩放、平移、基础颜色、主题与释放行为。用户提供的私有模型不能提交为测试 fixture 或公开截图。

本地大场景回归可设置 `EMBER_MODEL_DENSE_C4D_FIXTURE` 指向一个超过旧 50 万三角形上限、仍在 400 万预算内的 C4D，执行 `cargo test -p ember-model-plugin dense_c4d_keeps_interactive_geometry`；测试检查超过旧 50 万上限的样本仍返回未简化的原始网格，压缩解码完整，且遵守新的面数预算。私有样本不随仓库分发。

加载期间沿用宿主延迟 140 毫秒显示的转圈等待状态；模型首帧绘制成功才上报 `presented()`，失败上报错误。加载百分比通过 SDK `loading()` 显示在宿主通用圆环内，信息栏仅保留文件事实和完成后的模型信息。10 秒是用户可接受的性能目标，不作为杀死解析任务的硬超时；实测包括原生解析、分块传输、解压及首帧绘制。

### 线条工程

C4D 保存的样条及线对象作为 LineSegments 进入三维场景，即使没有三角形也保留旋转、缩放和平移。保留各段断开、闭合状态、对象层级变换与对象颜色；Bezier 按每边 12 段采样，其他未保存插值缓存的样条暂以控制折线显示，不执行生成器。线条与网格共用归一化边界，可混合显示。最多 100 万条线段，按需绘制，不转成管状网格。

原生载荷先存网格，后存线端点；render 的 meshTriangles 声明包含布尔刀具的实际网格三角形数，lines 声明线段数。每端点同样占 9 个 float32（法线为零），网页校验总字节数为 meshTriangles × 108 + lines × 72。解压预算相应包含最多 72 MB 的线端点。
