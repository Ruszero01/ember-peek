## 正式发布前仍需完成

1. 运行固定 Rust 1.99.0 的发布工作流门禁，构建并验证最终安装包。
2. 按[Windows 验收矩阵](testing.md)确认 Explorer、托盘、窗口回收、升级与未保存草稿保护，以及新插件真实文件显示与音频输出。
3. 开机自启需要真实安装后的注销／重启与卸载验收。代码已补齐 StartupApproved 清理；当前 Tauri 默认安装器原本已清理 Run 项，上一轮残留 Run 项的结论已更正。更新模式保留两项状态，详见[自启规范](specs/start-with-windows.md)。
4. 自启开关只读 Run 值，不反映任务管理器的禁用状态，显式设置时清理失败已改为返回错误且不继续修改 Run 项；需要验收“任务管理器禁用 → 应用关闭再打开 → 登录恢复”路径，避免把开关亮起当作实际登录启动的证明。
5. 自动更新需要已编译宿主与真实新版本，验证默认关闭、后台更新、草稿暂缓、下载期间关闭与卸载，不以网页 HMR 代替。
6. 先发布并验证插件目录，再交付宿主；GitHub 先预发布，人工确认后才晋级正式版。不得使用 --replace-baseline。
