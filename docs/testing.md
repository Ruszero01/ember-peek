# 测试与质量门禁

## 自动化层次

| 层次 | 命令 | 覆盖范围 |
| --- | --- | --- |
| 格式 | `npm run format:check` | 全 workspace Rust 格式 |
| 静态检查 | `npm run lint` | 全 workspace、全部 target/feature 的 Clippy，warning 视为失败 |
| 前端构建 | `npm run build` | 图标目录同步、TypeScript、Vite 生产构建 |
| 插件构建 | `npm run plugins:build` | 清单、引用边界、JS 语法、native 版本、开发市场 |
| Node 测试 | `npm run test:js` | SDK、MessagePort、UI、宿主命令接线、工坊 Agent、发布和 ZIP 协议 |
| Rust 测试 | `npm run test:rust` | 文件写入、运行时、市场、生命周期、网络、工坊与原生插件 |
| 完整 CI | `npm run ci` | 版本、发布日志及上述全部门禁 |

测试应围绕公开行为和边界：清单输入输出、桥接消息、文件系统事务、网络策略、生成包内容。
只有布局结构无法通过行为接口观察时，才使用源码或 DOM 结构断言。

## CI 触发

普通分支推送和 Pull Request 不触发远程构建；开发者应先在本机运行 `npm run ci`。
`Manual baseline checks` 只在维护者显式操作时运行。推送与版本一致的 `v*` 标签会触发
`Release Windows desktop`，在同一个发布任务中执行完整 CI 并仅构建一次安装包。插件发布
同样只允许手动触发，且在生成可发布产物前执行统一门禁。

## 手动 Windows 验收

自动化无法替代以下系统集成检查：

1. Explorer 单窗口多标签页、多个窗口、地址栏/搜索框/F2 重命名下的空格键行为。
2. 托盘、首次启动、窗口隐藏与 120 秒 WebView2 回收。
3. 插件安装、覆盖更新、卸载，以及有未保存内容时的拒绝路径。
4. 真实拖放、文件选择、剪贴板、主题和语言切换。
5. 在默认应用中打开：交给真实的系统关联程序，无关联格式的回退行为，以及预览窗口内容不受影响。
6. 工坊真实模型供应商、取消、断网恢复、试预览窗口和截图回传。
7. Markdown 的 `./`、`../`、绝对路径、`file:` 与公开 HTTP(S) 图片；失败资源应降级而不
   破坏正文。
8. 窗口位置与大小的记忆：拖动、缩放到非默认值后重启宿主，窗口回到原处；最大化后重启仍是
   最大化，取消最大化回到最大化之前的大小；显示器变化后不留在屏幕外。步骤见
   [Windows 桌面](windows-desktop.md) 的手动验收。
9. 沉浸模式下图片预览的「窗口对齐图片」设置（默认开）：打开图片时窗口**第一次出现就**是图片的
   形状（不是先按默认尺寸出现再跳）；横图高度跟着宽度收敛，竖图反过来（宽度跟着高度收敛，窗口
   不会长成比屏幕还高），画面从边到边没有留白，不需要任何按钮。随后自己调整窗口大小，画面回到
   适应窗口而不是被拉伸；关掉该设置再打开图片，窗口保持用户自己的大小；连续看一张竖图再一张横图，
   窗口不应一次比一次窄（插件声明的尺寸不进入用户的记录）；窗口保持可见时切换横图与长截图，尺寸应立即跟随新图片；976×4065 长截图在约 814 高时所需宽度低于 320，下限会使高度等比增加，若因此超出屏幕则限制高度并居中适应。1154×181 宽图声明的高度低于 240 时，窗口应等比增宽增高；若宽度超出屏幕则限制宽度并居中适应，上下控件不能碰在一起。沉浸模式点「适应窗口」或打开一张窗口形状不匹配的图片时，图片应以完整窗口为界贴住限制边，不因浮动栏留出上下空带；普通模式仍保留安全距离。
10. 连续预览超过 16 个不同文件：已完成的旧文件自动退出最近 4 组缓存，不出现会话上限提示；快速切回最近文件应复用已有解析。切走尚未完成的大文件后再切回仍继续原有加载；编辑器有未保存草稿时，缓存淘汰不能删除草稿。
11. 沉浸模式打开横向、竖向视频：有元数据时首次显示就按画面形状开窗，切换到另一段视频时立即调整且位置不动；没有 ffprobe 时由媒体元数据补报，慢文件不能卡住窗口。小于 320×240 下限或被屏幕限制时，视频居中完整显示；手动拖动窗口后不裁切。普通模式把两条栏高度计入窗口声明，播放时浮动栏始终可见。
 12. 视频设置里的「导出位置」：留空时点「导出当前帧」把 PNG 写在源视频旁边，画面上出现的提示卡片给出写出的完整路径；用「浏览…」选一个目录后，再点一次直接写进新目录且**不再出现任何确认框**；把该目录删掉再导出，提示卡片应明确报错，而不是悄悄写回源目录或别处；把设置改回空，导出回到源视频旁边。同目录下同名帧连续导出应为新文件让位，不覆盖已有文件。

运行手动验收时使用已有开发服务器，不在自动化脚本中隐式启动或停止它。

## 当前覆盖缺口

- Windows Explorer COM/UI Automation 与全局键盘钩子只能在真实桌面会话验证。
- WebView2 媒体解码能力取决于系统运行时和编解码器。
- 两个真实模型供应商测试默认 `ignored`，仅在显式提供凭据和地址时运行。
- 尚未设行覆盖率百分比门槛；当前以协议分支、失败路径和回归用例完整性作为合并标准。

## 宿主更新与发布晋级

- 关于页：检查中禁用重复操作；无新版本、发现新版本和网络失败的反馈；下载仅打开浏览器。
- OSS 正式版本有效时不请求 GitHub；OSS 不可达、返回无效元数据或预发布版本时回退 GitHub；双方失败时允许重试。
- 推送测试标签后只有 GitHub 预发布；转为正式发布后才镜像 OSS，校验安装包字节不变、校验和正确、稳定指针最后切换；重复发布和旧版本晋级不得覆盖新版本。
## PDF 初版手动验收

- 「适配窗口」按钮开启时高亮、铺满，关闭时完整显示整页；手动缩放取消高亮。设置「默认适配窗口」默认开启，修改立即生效、下次打开沿用默认，按钮临时切换不修改默认设置。

- 单页模式左右翻页，上下只滚动当前页；连续模式左右平滑跳页，上下滚动文档。连续按左右键、中途滚轮／上下键打断、首尾边界和减少动态效果时均应正确定位；输入框聚焦时不抢占方向键。

- 在 PDF 插件设置中切换单页／连续模式：立即生效、保留页码；连续滚动同步页码，跳页定位正确，远处页面画布被释放；缩放、旋转、窗口变化及混合尺寸页面继续可读。

- 从本地市场安装 PDF 预览，确认版本 0.1.0；分别打开普通多页、扫描件、中文内嵌字体和横竖混合页面。
- 检查首页显示、页码拖动、左右键翻页、Home／End、缩放、滚动、适配窗口、旋转和窗口缩放。
- 快速连续翻页及旋转应最终显示目标页面；切换文件、隐藏与重新打开窗口后可继续预览。
- 检查浅色／深色、沉浸模式、两条栏显隐；视口不应出现自绘工具栏。
- 检查损坏与加密 PDF 的明确失败提示、大文件按需读取、超大页面的画布上限，以及断网后的字体与页面显示。

## PDF 编辑初版验收

- 预览停在第 2 页中部，切换 PDF 编辑仍为第 2 页同一页内位置；反向切换、尺寸变化及保存刷新均不回到第一页。
- 在文字选择浮层修改／清空片段，更换黑体输入中文，保存后通过独立 PDF 阅读器确认旧文字已替换或删除；不依赖覆盖图形。
- 用真实文件选择框替换 PNG/JPEG，确认图片像素改变而位置和占位尺寸保留。
- 插入空白页、确认删页、撤销与放弃草稿；最后一页不能删除；保存后顺序及页数正确。
- Ctrl+S 保存浮层尚未应用的文字，文字输入框 Ctrl+Z 正常；视口 Ctrl+Z 撤销草稿操作；左右翻页／上下滚动不抢输入焦点。
- 外部修改、只读、签名／权限受限及文件锁保存失败时，保留草稿且不覆盖外部内容；预览插件仍只读。
- 浮层与宿主栏保持置顶，沉浸模式留白正确；后台编辑草稿不被阅读位置同步覆盖。

PDF 编辑图片缩放验收：选择图片，拖动四角确认对角固定、比例保持；Escape／取消不产生草稿，松开后可以撤销，保存并重新打开尺寸仍保留。检查亮／暗主题下共享文件选择、按钮焦点和禁用状态。

视图生命周期验收：打开同时匹配预览／编辑的文件，在编辑器前台停留超过 120 秒后切回尚未激活的预览；再次在预览初始化中切离并等待超过 120 秒，返回时不得出现初始化超时。真正可见且未调用 presented 的视图应在 120 秒后报错，后台原生解析和未保存草稿仍受保护。
